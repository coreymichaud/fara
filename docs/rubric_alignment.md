# Honest rubric alignment

| Criterion            | Demonstrable evidence                                                                                                                   | Do not claim                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Innovation / novelty | Complete evidence → scenario → practitioner challenge → public brief → community check loop                                             | A novel causal model or proven nutrition outcome                                            |
| UX                   | Responsive map-first workspace, local tile-failure fallback, keyboard controls, readable caveats, mobile survey                         | Full WCAG certification from one automated audit                                            |
| Impact               | Helps pantry practitioners formulate and question a concrete event proposal                                                             | People fed, food insecurity reduced, attendance improved                                    |
| Functionality        | Real supplied-data joins, editable weights/radius/capacity, deterministic comparisons, persistent plans, protected survey aggregates    | A production-ready service network or approved venues                                       |
| Data science         | Executed source EDAs, explicit denominators/vintages, exact key joins, deterministic versioning, missing-value handling and sensitivity | Statistical confidence percentages or correlation as causation                              |
| Teamwork             | Clear demo/slide/video handoff artifacts and suggested presentation roles                                                               | Work performed by people who have not actually done it                                      |
| Execution            | Actual local checks and coverage reports, Docker image with permitted processed assets and no raw data                                  | A live deployment until an actual URL has passed smoke checks                               |
| Google tooling       | Firestore Admin adapter verified with the Firestore Emulator; local Docker → Artifact Registry → Cloud Run deployment path              | An invented Gemini integration or unperformed cloud deployment                              |
| AI assistance        | AI-assisted engineering is documented openly                                                                                            | Generative AI functionality in the application                                              |
| Presentation         | Exact two-minute click path, five-slide outline, 80-second video shot list, real screenshots                                            | A generated `.pptx`, published YouTube video, fabricated testimonials or survey respondents |
