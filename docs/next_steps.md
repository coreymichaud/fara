# Next steps

## Before the hackathon presentation

1. Review the verification report and screenshots. Run the two-minute click path with a fresh plan and a second browser, using **Suggested areas**, **Area details**, **Event settings**, and **Compare locations**. Check **Areas / Map / Plan** on a phone.
2. Complete Google Cloud account/project prerequisites, then run the local-image deploy script and smoke-test the returned URL. Verify Firestore persistence across a redeploy before claiming it.
3. Assemble the five-slide PowerPoint, record the short video, and upload through the team’s account.
4. Keep private creator links out of public slides, recordings and shared documents.

## Before planning an actual event

Verify venue permission, current services, physical accessibility, food storage/handling, staffing, safety, permits and operating costs with the responsible organization. Ask community partners whether the proposed geography/time is useful. Update stale indicators and record the retailer snapshot capture date. A candidate tract point is only a starting zone.

## Data gaps with the highest value

Validated pantry locations, actual event capacities/service schedules, and comparable operational definitions would support cautious baseline-overlap analysis. Finer population allocation could improve proximity estimates if defensible and licensed. Community sampling/recruitment design matters more than a larger convenience-sample n. Transport modeling would require real Central Florida service/network data and a separate validated model; it is outside the present MVP.

## Product and operations

Review anonymous survey abuse protection, retention/deletion policy, provider log settings, creator-token recovery tradeoffs, accessibility with screen readers, and field usability. Add monitoring/alerts and a clear owner for source refreshes. Supply licensed Avenir WOFF2 assets for consistent cross-device typography. Keep private organizational data and generative AI outside this prototype’s scope unless a new specification explicitly authorizes them.
