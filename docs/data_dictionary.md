# Published data dictionary

Only five minimized JSON/GeoJSON assets in `public/data/` enter the production image. All generated web assets and intermediate data are Git-ignored. Schema version `1.0`; model `priority-proximity-v1`.

| Field                   | Source / lineage                                                                       | Type and units                                                                             | Null / interpretation                                                                |
| ----------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| `id`                    | ACS `GEO_ID`, prefix `1400000US` removed; USDA `CensusTract20`, zero-padded            | 11-character 2020 GEOID                                                                    | Required unique key, never numeric arithmetic                                        |
| `label`                 | ACS S1701 `NAME`, part before first `;`                                                | Census tract label                                                                         | Does not name a neighborhood or venue                                                |
| `county`                | ACS S1701 `NAME`, second `;` part, ` County` suffix removed                            | County name                                                                                | Exact study-area filter                                                              |
| `coordinates`           | Interior representative point of official 2020 tract geometry, calculated in EPSG:5070 | `[longitude, latitude]`, WGS84 degrees                                                     | Not a venue, household, or population-weighted centroid                              |
| `poverty`               | ACS S1701 `S1701_C03_001E`                                                             | Percent of population with determined poverty status below threshold, 2020–2024            | Null preserved; positive direction in index                                          |
| `povertyMoe`            | ACS S1701 `S1701_C03_001M`                                                             | 90% margin of error in percentage points                                                   | Not a probability/confidence score                                                   |
| `lowAccess`             | USDA `SD_SRAM_lapop1share`                                                             | Percent of 2020 population over 1 straight-line mile from a 2025 SNAP-authorized foodstore | Same 1-mile threshold for urban/rural comparability; not transit/road distance       |
| `snap`                  | ACS S2201 `S2201_C04_001E`                                                             | Percent of households receiving SNAP, 2020–2024                                            | Context only, not eligibility gap or index component                                 |
| `population`            | USDA `POP2020`                                                                         | 2020 Census people                                                                         | Used to exclude zero-population tracts; never mixed with household slots             |
| `households`            | USDA `OHU2020`                                                                         | 2020 occupied housing units                                                                | Whole-tract counts assigned to a representative point; not measured catchment demand |
| `urban`                 | USDA `Urban`                                                                           | Boolean source classification                                                              | Context; does not change the common 1-mile indicator                                 |
| Retailer `id/name/type` | `Record_ID`, `Store_Name`, `Store_Type`                                                | Public store metadata                                                                      | Not pantry/service metadata                                                          |
| Retailer point          | `Longitude`, `Latitude`                                                                | WGS84 longitude/latitude                                                                   | Source `X/Y` Web Mercator fields are not used                                        |

`tracts.geojson` properties hold only `id` and representative coordinates. The client attaches computed priority and included-state through MapLibre feature state. `counties.geojson` dissolves selected tract boundaries by five-digit county FIPS. `retailers.geojson` excludes private/address/contact fields and one known coordinate anomaly.

`manifest.json` records schema/method/data versions, generation time, geographic extent, counts, null counts, units, source vintages, SHA-256 hashes of original files (no contents), hashes of web assets, publication basis, and the absence of baseline services. Rebuilding refreshes generation time, not source observation years. Rebuilding identical inputs produces identical data payloads and dataset version.

Firestore contains immutable plan snapshots, a hash of a separate random creator secret, mutable survey-enabled state, a transactionally updated response count, and four-choice response documents. No raw Beacon tables, geometries, IPs, survey free text, or client-side database credentials are stored there.
